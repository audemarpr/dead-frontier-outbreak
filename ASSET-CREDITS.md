# Dead Frontier: Outbreak V3.0 asset credits

The shipped game uses selected models and clips from these sources. The Quaternius, Poly Haven and city kit assets use CC0 1.0. The following Vinish assets use CC BY 4.0.

| Source | In-game use and adaptation |
| --- | --- |
| [Quaternius Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) | Standard male full-body mesh with original skin weights, compact textures and clothing material regions and an optional head-weighted buzz cut. Infected and survivor variants use the same rig. |
| [Quaternius Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) | Idle, walk, jog, sprint, pistol stance, shoot, reload, jab, cross, lowered pistol pose, hit, pickup, interaction and death. Rotation tracks were adjusted between the source and target rest poses. Pelvis translation was scaled to target height. |
| [Quaternius Universal Animation Library 2](https://quaternius.com/packs/universalanimationlibrary2.html) | Zombie idle, forward walk, scratch, hook and consume. |
| [Poly Haven](https://polyhaven.com/license) | Covered Car, Rollershutter Window 01, Shrub 01 and Service Pistol. Mobile derivatives retain PBR materials and reduce texture resolution and geometry. Original 1K photographic diffuse, OpenGL normal and roughness maps for aerial_grass_rock, asphalt_01 and wood_plank_wall are also included. |
| [Kit Cidade Low Poly](https://github.com/kayquer/kit-cidade-lowpoly/tree/d9de7e25d476d8b8572971840b129c28a68e9cf7) | Warehouse (galpao). The stylized model supplements the photographically textured environment. |

### Captured survivor movement

The data used in this project was obtained from [mocap.cs.cmu.edu](https://mocap.cs.cmu.edu/). The database was created with funding from NSF EIA-0196217. Trials 02_01 (walk), 02_03 (jog) 09_01 (run) and 104_41 (acted zombie walk) were cropped to individual cycles, aligned to foot contacts and retargeted to the survivor skeleton. The game supplies translation. The animation retains vertical motion and lateral weight shifts. [CMU usage terms](https://mocap.cs.cmu.edu/faqs.php) · [BVH conversion mirror](https://github.com/una-dinosauria/cmu-mocap)
